Setup Instructions

Please download the SheetJS library to enable Excel file parsing:

  1. Visit: https://cdn.sheetjs.com/xlsx-0.20.1/package/dist/xlsx.full.min.js
  2. Save the file as xlsx.full.min.js in the lib folder
  3. Or copy the following command:
# PowerShell command:
Invoke-WebRequest -Uri "https://cdn.sheetjs.com/xlsx-0.20.1/package/dist/xlsx.full.min.js" -OutFile "lib\xlsx.full.min.js"
