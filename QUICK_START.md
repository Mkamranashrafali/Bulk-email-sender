# Smart Mail Pro - Quick Start Guide

## 🚀 Getting Started

### First Launch
When you open Smart Mail Pro for the first time, you'll see:
- **Welcome screen** with the app name "Smart Mail Pro"
- **Tagline**: "Turn your CSV into personalized emails — fast & easy."
- **Two plan options**: Free Plan and Pro Plan
- **"Start Free Trial"** button

### Free Plan (Default)
Click **"Start Free Trial ✨"** to begin with:
- 3-day free trial period
- Up to 20 emails
- Preview functionality
- Basic features

### Method 2: From Any Screen
1. Look for the **"Go Pro ✨"** button in the top-right header
2. Click it to open the activation screen
3. Enter license key: `activate@`
4. Click **"Activate Pro 🔑"**
5. Wait for success message
6. You'll be automatically redirected back

## ❓ Troubleshooting

### "Invalid license key" Error
- Double-check spelling: `activate@`
- Ensure no extra spaces
- Try copy-pasting the key
- Refresh and try again

### Features Still Locked After Activation
- Check header shows "Pro Active ✓"
- Verify email counter shows "∞ Unlimited"
- Try refreshing the extension
- Check Chrome storage isn't full

### Email Limit Not Updating
- Status persists across sessions
- Counter only updates on actual sends
- Try reopening extension
- Check saved state in Chrome storage

### Can't Access Upgrade Screen
- Look for "Go Pro ✨" in header
- Click it from any screen
- Alternative: Return to welcome
- Button always visible when logged in
