## 🆘 Troubleshooting

### Extension won't load?
- Check all files are present
- Verify `xlsx.full.min.js` is in `lib` folder
- Look for errors in Chrome Extensions page

### Icons not showing?
- Run `make-icons.ps1` in PowerShell
- Check `icons` folder has PNG files

### Variables not detecting?
- Use format: `[VariableName]` with square brackets
- Make sure you have text in template
